# Clothing Review Analysis

## 📌 Dataset Source
The dataset used in this project is **Womens Clothing E-Commerce Reviews.csv**, which contains customer reviews for various clothing items. The data includes attributes such as clothing category, review text, rating, and customer age.

## 🚀 What This App Does
- Loads and processes the dataset.
- Performs sentiment analysis on customer reviews.
- Generates visualizations and insights using Streamlit.
- Provides an interactive UI to explore the reviews.

## 📝 How to Run
Ensure you have the required dependencies installed:
```bash
pip install -r requirements.txt
```

Run the script:
```bash
python examples/clothing_review/hello.py
```

## 🛠 How to Deploy
You can deploy this application using **Preswald**:
```bash
preswald deploy examples/clothing_review/
```
